## Description & Technology

 This is a News Explorer front end (Sprint 16 final project). The code is on the stage-1-frontend-api branch. main only has a one-line README.
 You search recent news, see article cards, and sign in to save or remove articles. Routes cover the home page and a saved-news page, plus login and registration modals.

## Technologies Used

  - **HTML5:** Used to structure the content and layout of the application.
  - **CSS3:** Used to style components, create layouts, and provide a responsive user interface.
  - **JavaScript (ES6+):** Used to implement application functionality, event handling, and interactive features.
  - **React 18:** Used to build reusable components and manage the application's user interface.
  - **React DOM:** Used to render React components into the browser's DOM.
  - **React Router DOM 7:** Used for client-side routing and navigation between application pages.
  - **Vite 6:** Used as the development server and build tool to provide a fast development environment and optimize production builds.
  - **Git & GitHub:** Used for version control and source code management.
  - **GitHub Pages:** Included as a deployment tool for hosting the application.
  - **gh-pages:** Used to support publishing the production build to GitHub Pages.
